# After Effects for mapped content — the harder things

Compiled 2026-10-29 from Adobe Help pages (helpx.adobe.com, read via Internet Archive snapshots; dates per claim). **[unverified]** = not confirmed from a primary source; **[derived]** = our own rule of thumb. After Effects' current release line is 25.x/26.x; page dates are 2024–2026.

---

## 1. Composition and colour setup

- `Composition > New Composition` (Ctrl+N). "Composition settings, including frame size (width and height) and pixel aspect ratio, are automatically set to match the characteristics of the footage item" when you use `File > New Comp From Selection` or drag footage onto the *Create a new composition* button — so dropping the mapper's **Shape PNG** on that button gives a comp at the projector's exact size. Save presets with the Save button next to *Preset* (Width, Height, Pixel Aspect Ratio, Frame Rate). `Composition > Composition Settings` = Ctrl+K. — https://helpx.adobe.com/after-effects/using/composition-basics.html (Jan 21 2026)
- Via Dynamic Link the comp "inherits" Premiere's dimensions, PAR and frame rate, default duration 30 s (see `premiere-workflow.md` §8). — https://helpx.adobe.com/after-effects/desktop/work-with-other-applications/work-with-dynamic-link/dynamic-link-effects.html (Mar 27 2026)
- Colour: "You turn color management on for a project by choosing a Working Color Space for the project under the Color tab of the Project Settings dialog box" (`File > Project Settings > Color`). "HDTV (Rec. 709) is a good choice if you're making a movie for high-definition television." "For best results, when working with 8-bpc color, match the working color space to the output color space." Display: `View > Use Display Color Management`. Output: "You choose an output color profile in the Output Module Settings > Color tab." — https://helpx.adobe.com/after-effects/desktop/adjust-colors/color-management/color-management.html (Mar 27 2026). Keep a Direct-709 Premiere sequence and a Rec.709 AE project together or Premiere warns on *Replace With After Effects Composition* (`premiere-workflow.md` §8).
- Immersive (VR) effects need GPU rendering: `File > Project Settings > Video Rendering and Effects > Use > Mercury GPU Acceleration`; "If your settings are set to Mercury Software Only, the effects do not render and display a warning banner." — https://helpx.adobe.com/after-effects/using/vr-effects.html (Jun 27 2025)

## 2. Guide layers (AE has them; Premiere does not)

"You can create guide layers from existing layers to use for reference in the Composition panel… By default, guide layers aren't rendered when you create an output but can be rendered when desired by changing the render settings for the composition." "Guide layers in nested compositions can't be viewed in the containing composition." `Layer > Guide Layer` toggles. In the Render Queue, *Render Settings* → *Guide Layers* menu: *Current Settings* renders visible guide layers, *All Off* leaves them out. — https://helpx.adobe.com/after-effects/using/layer-properties.html (Apr 15 2026)

Pattern [derived]: import the mapper's Guide SVG (as shapes in beta AE, or rasterised PNG, §3), put it on top, `Layer > Guide Layer`, then it shows while you work and vanishes on render — and through Dynamic Link to Premiere, because the linked comp is rendered by AE and guide layers are "not rendered… by default" **[derived from the documented default; not separately tested through Dynamic Link]**. Note the community-reported bug where `Composition > Save Frame As` rendered guide layers (community.adobe.com, 2023) **[unverified]**.

## 3. Vector input: SVG, Illustrator, shapes

- **SVG import is a beta feature** as of the Nov 13 2025 page: "SVG file import is now available for testing and feedback. Try it now in After Effects (beta)… Every element in these files, such as paths, fills, strokes, and groups, is converted into native shape layers." Import with `File > Import > File` or by double-clicking the Project panel; inspect via the Properties panel *Layer Contents*. Known limitations: "there is no reference to the original SVG in the Project panel, and Collect Files will not include the SVG source"; "SVG Text will not be imported… convert text to curves"; "Animated and raster SVGs are not supported"; "SVG compositions currently import with a 1-frame duration." — https://helpx.adobe.com/after-effects/using/import-svg-files.html. (Localised copies of the page updated mid-2026 describe *Footage* vs *Composition* import choices and clipboard paste of SVG — search snippets only **[unverified]**.) The mapper's guide uses `<text>` for point labels; those will not come across — keep the rasterised PNG guide for the numbers.
- **Release AE route**: open the SVG in Illustrator, save `.ai` (artboard = projector pixels), import into AE as *Footage*, then `Layer > Create > Create Shapes from Vector Layer`: "A matching shape layer appears above the footage layer, and the footage layer is muted." Caveats: "Converted shapes ignore PAR overrides"; "Gradients and unsupported types may show 50% gray shapes"; "The menu command works on a single selected layer at a time"; a multi-layer `.ai` comp can't be converted in one pass — import as footage first. Gradient fills/strokes are retained in the Illustrator-layer workflow. — https://helpx.adobe.com/after-effects/desktop/drawing-painting-and-paths/shapes-and-shape-attributes/creating-shapes-masks.html (Jan 21 2026)
- Once the surface outlines are shape layers you can use them directly as **track mattes** (§4), stroke them for "wireframe" reveals (Trim Paths), or turn the cell-door outline into an animated glow **[derived use]**.

## 4. Track mattes in current After Effects

"Any layer in your composition, no matter where it sits in the layer stack, can be used as a Track Matte source for any other layer. You can even have multiple layers all reference a single layer for their matte." The *Track Matte* menu "shares a column with the blending modes menu" (show the *Modes* column); pick the matte via the *Layer List dropdown* or the pick whip; two toggles choose **Alpha Matte / Luma Matte** and **Inverted / Non-Inverted** ("Alpha Inverted Matte", "Luma Inverted Matte"). "By default, when a layer gets selected as a track matte, the visibility of the track matte layer gets off." "To animate a Track Matte to move with the layer that it's matting, make the Track Matte a child of the layer it's matting." Precompose content + matte to animate them together. — https://helpx.adobe.com/after-effects/using/track-mattes-and-traveling-mattes.html (Oct 14 2024)

For the mapper's PNGs (opaque, alpha 255 everywhere): **Luma Matte**. One matte layer can serve every surface's content layer.

## 5. Organic growth, particles, displacement

All page dates 2025–2026; effect names are the menu names.

- **Fractal Noise** (`Effect > Noise & Grain`): "uses Perlin noise to generate grayscale noise that you can use for organic-looking backgrounds, displacement maps, and textures, or to simulate clouds, fire, lava, steam, flowing water, or vapor." Loops: "The primary reason to use the Fractal Noise effect instead of the Turbulent Noise effect is for the creation of looping animations, since the Turbulent Noise effect doesn't have Cycle controls." Procedure: set two *Evolution* keyframes, tick *Cycle Evolution*, set *Cycle (in Revolutions)* to divide the Evolution revolutions; "Initially, the last frame of a cycle is identical to the first frame. To create a seamless loop, skip the last frame by setting the Out point of the layer one frame before the last frame of the cycle." Pre-render the cycle and loop the movie. — https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/noise-grain-effects.html (Jun 17 2026)
  - Frost / creep / cracks [derived recipe]: animate a *Levels* or *Curves* threshold on a Fractal Noise layer so the white area grows over time (noise as a growth map), use it as a Luma Matte over a frost or crack texture, and feather with a small blur. Reverse the keyframes for melting.
- **Displacement Map** (`Effect > Distort`): "distorts a layer by displacing pixels horizontally and vertically based on the color values of pixels in the control layer… A color value of 128 produces no displacement." "The effect uses the control layer… without considering any effects or masks. If you want to use the control layer with its effects, precompose it." — https://helpx.adobe.com/after-effects/using/distort-effects.html (Jun 27 2025). Use the mapper's Shape PNG precomposed with a blur as the control layer to make content "cling" to the shape edge **[derived]**.
- **Turbulent Displace**, **Corner Pin** ("You can move the corner pins in the Composition panel, the Timeline panel, or the Effect Controls panel"), **CC Power Pin** are on the same page.
- **CC Particle World** ("particles move freely in 3D space with customizable… color, speed, and size"), **CC Particle Systems II** ("fire, smoke, explosions, or dust"), **CC Sphere** ("Turns a layer (like an image or video) into a 3D sphere"), **CC Rainfall**, **CC Snowfall**, **CC Pixel Polly** are Cycore effects "pre-installed" with AE. — https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/cycore-plugins.html (Jun 16 2025). CC Sphere is listed under *Perspective* (perspective-effects page, search snippet).
- **Shatter** (`Effect > Simulation`): "explodes images… You can even use a gradient layer to… " control order: *Gradient Layer* — "White areas shatter first; black areas shatter last"; *Shatter Threshold* animated from 0 % upward times the break-up. **Particle Playground** generates dots, a layer, or text characters with Cannon / Grid / exploders. — https://helpx.adobe.com/after-effects/using/simulation-effects.html (Jun 26 2025). Cracking brick / collapsing cell-door [derived]: Shatter with a gradient layer painted so cracks start at the door frame.
- Everything above renders black where there is nothing; keep comp background black (`Composition Settings > Background Color`) and remember nested comps "become transparent" inside a parent (composition-basics page). Black is "off" on the projector, so no keying is needed when you bring the comp into Premiere [derived].

## 6. Spheres: the 2:1 strip for the moon

- **What the mapper wants**: a **2:1 equirectangular** video; middle of the strip faces projector 1, left/right edges meet behind the ball, top row = north pole; 2048×1024 is plenty for a 60-inch ball from 1080p (mapper `README.md`, "All the way round a ball"). Make the AE comp **2048 × 1024**, square pixels, 30 fps.
- **Authoring in the strip directly** [derived, standard practice]: paint/animate in the rectangle, keep text and faces within about ±35° of the equator (rows 25 %–75 % of the height) where the stretch is small, make the left and right edges tile (Offset by exactly one width per loop for drifting clouds), and avoid putting anything important at the poles (rows near 0 and 1024 collapse to points).
- **Checking the look / wrapping flat art onto a globe**: *CC Sphere* turns a layer into a 3D sphere — good for a preview of how the strip wraps, not for the deliverable (the mapper does the wrap). — cycore-plugins page (Jun 16 2025).
- **VR Converter** (`Effect > Immersive Video > VR Converter`): "convert your footage from 2D source, equirectangular, cubic, or spherical layouts to other VR layouts. You can also change the orientation of your footage." Input formats include *2D Source*, *Equirectangular 2:1*, *Equirectangular 16:9*, *Fisheye (FullDome)*, *Sphere-map*, several cube-maps; output formats include *Equirectangular 2:1*, *Equirectangular 16:9*, cube-maps and *Fisheye (FullDome)*. Re-orient with *Tilt (X-Axis)* / *Pan (Y Axis)* / Roll. Needs GPU rendering. — https://helpx.adobe.com/after-effects/using/vr-effects.html (Jun 27 2025). Use it to (a) rotate a finished strip so a feature faces projector 1 (*Pan*), (b) place a flat 2D source (a face, a logo) onto the sphere without manual distortion (*2D Source → Equirectangular 2:1*), or (c) convert cube-map or fisheye stock. The other `Immersive Video` effects (VR Blur, VR Glow, VR Color Gradients, VR Sharpen, VR Denoise, VR Digital Glitch, VR Fractal Noise, VR Chromatic Aberrations…) "compensate for distortion in equirectangular content" so they do not break at the seam (same page).
- `Composition > VR > Create VR Environment` / *Extract Cubemap* build master-camera rigs for 360 compositing — more than this job needs, but documented at https://helpx.adobe.com/after-effects/using/immersive-video-VR.html (Apr 21 2026).
- Export of the strip: Premiere/AME can flag the file as VR (*Video Is VR*, Frame Layout, fields of view) — **do not** tick it for the mapper; it only adds metadata for VR players (export settings reference, Aug 18 2026). Plain H.264 2048×1024 is what the mapper and `bake.js` read.

## 7. Getting the result out

- Dynamic Link back to Premiere is the normal route (`premiere-workflow.md` §8). Heavy comps: `Clip > Render and Replace` in Premiere.
- Direct from AE: `File > Export > Add to Render Queue`, *Output Module* → *Format* **H.264**, *Format Options* for Video/Audio/Multiplexer ("Native H.264 Encoding allows you to use the Adobe Media Encoder (AME) UI… without leaving After Effects… supports both hardware and software encoding modes"). — https://helpx.adobe.com/after-effects/using/exporting-h264-from-the-after-effects-render-queue.html (Feb 26 2024). "The embedded version of the Adobe Media Encoder used… within After Effects output modules does not provide all the features of the full, stand-alone Adobe Media Encoder application"; you can also add comps "to the Adobe Media Encoder queue". — https://helpx.adobe.com/after-effects/desktop/render-and-export/basics-of-rendering-and-exporting/basics-rendering-exporting.html (Mar 27 2026)
- Hap from AE: the disguise exporter adds "Quicktime HAP Format" to output modules (only tested in CC 2019/2020; see `export-and-playback.md` §5).
