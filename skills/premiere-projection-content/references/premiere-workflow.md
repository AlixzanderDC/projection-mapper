# Premiere Pro workflow for mapped content — verified procedures

Compiled 2026-10-29 from Adobe Help (helpx.adobe.com) pages read through Internet Archive snapshots dated 2025–2026 (helpx refuses direct automated fetches; snapshot dates are given per claim), Adobe Learn pages, and the mapper's own `README.md` / `js/export.js`. Anything not confirmed from a primary source is tagged **[unverified]**; our own rules of thumb are **[derived]**. Premiere Pro's current release line at the time of writing is 26.x (release notes list 26.5.2, September 2026); the pages quoted describe 25.x–26.x unless noted.

---

## 1. What the mapper hands you

From `js/export.js` (read 2026-10-29):

- **Shape PNG** (`silhouettePng`): rendered at `output.width × output.height`, every visible surface filled white, black elsewhere, feather and masks' feather zeroed, blend ramps off, brightness 1, gamma 1, software flip forced to `none` ("the stencil is the upright frame"). **The alpha channel is forced to 255 on every pixel** (`img.data[i] = 255`), so the file has *no transparency*: it is a luma matte, not an alpha matte. Hard-edged (no anti-aliased feather).
- **Guide SVG** (`guideSvg`): `width`/`height`/`viewBox` = projector pixels, a 1-px grey frame rectangle, per surface a `<g id="surface name">` with white 50 %-opacity warp-grid polylines (one through each control row/column), a 2-px cyan `#2ee6ff` outline, a dashed pink `#ff6ad5` mask polygon when a mask is enabled, orange `#ffb020` control-point circles labelled `row,col`, the surface name in cyan, and a footer "`<projector> · W×H · make content at this size and show it with a Full frame surface`". Text uses `font-family="sans-serif"`.
- **Matte per surface zip** (`surfaceMattesZip`): one Shape PNG per *visible* surface, named `<prefix>_<surface name>.png` (non-word characters replaced by `_`, duplicates suffixed `_2`, `_3`…). Stored, not compressed.

From `README.md` ("Content template", "All the way round a ball", "Bake a projector's picture"):

- Make the video at the projector's size, drop it in `media/`, add a surface, press **Full frame**, pick the video. "Nothing else to warp: the content already has the shape."
- A **360° ball** surface takes a **2:1 equirectangular strip**: "its middle lands on the point of the ball facing projector 1, its left and right edges meet behind the ball, the top row is the north pole"; moving right in the strip travels round the ball to the right as seen from projector 1. "2048×1024 reads well on a 60-inch ball from 1080p projectors."
- `tools/bake.js` writes a plain H.264 MP4 at the projector's resolution; `--loops N` repeats the file "so the player's restart gap comes rarely"; FAT32 cannot hold a file over 4 GB.

## 2. Sequence setup

**Create the sequence** — `File > New > Sequence`, pick a preset on the *Sequence Presets* tab, change the *Settings*, *Tracks* or *VR Video* tabs, name the preset and select OK to save it. "Every editing mode does not support every possible frame rate… select Custom as the Editing mode. Then, select the … frame rate from the Timebase menu." — https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/create-a-custom-sequence-preset.html (Jan 7 2026)

**Settings tab fields** (Sequence settings reference, Jan 7 2026, https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/sequence-settings-reference.html):

- *Editing Mode*: "The Custom editing mode allows you to customize the other sequence settings." The editing mode "does not determine the format of your final movie."
- *Timebase*: time divisions for edits — use **30** for a 30 fps projector (the page's examples are 24 / 25 / 29.97).
- *Frame Size*: "The maximum frame size for a sequence is 10,240x8,192." Enter the projector's native pixels (1280 × 768, 1920 × 1080).
- *Pixel Aspect Ratio*: "Choose Square Pixels for analog video, scanned images, and computer-generated graphics… If you use a pixel aspect ratio different from the pixel aspect ratio of your video, the video often gets rendered with distortion."
- *Fields*: "Select No Fields (Progressive Scan) if you work with progressive-scan video."
- *Working color space* and *Auto Tone Map Media* are listed on the same tab (see §3).
- *Maximum Bit Depth*, *Maximum Render Quality* ("Maintains sharp detail when scaling from large to smaller formats… often makes highly compressed image formats, or those containing compression artifacts, look worse because of sharpening"), *Composite In linear color* ("can provide a more photo-realistic look for blended frames… Linear fades look smoother with this option turned off").
- *Save Preset*: "opens the Save Settings dialog box, where you can name, describe, and save your sequence settings."

Adobe's aspect-ratio page: "The sequence settings preset you choose when you create a sequence sets the frame and pixel aspect ratios for the sequence. You can't change aspect ratios after you create the sequence." (search snippet of https://learn.adobe.com/premiere-pro/using/aspect-ratios.html; page not fetched) **[unverified wording]**

**Sequence from a still's dimensions**: the Project-panel context command *New Sequence From Clip* creates a sequence matching the clip **[unverified: command name not confirmed on helpx this pass]**. Safer: make the preset by hand from the Shape PNG's pixel size, which you know exactly. (After Effects has the equivalent documented: `File > New Comp From Selection` sets frame size and PAR from the footage — see `after-effects.md`.)

Frame-size sanity: Premiere imports stills up to 256 megapixels / 32,768 px on a side (https://helpx.adobe.com/premiere/desktop/organize-media/import-files/supported-file-formats.html, Sep 30 2026), so projector-sized mattes are never a problem.

## 3. Colour management: keep it plain Rec.709 SDR

- "When you make a new sequence, by default it's set to Broadcast 709 (SDR) color setup preset, and the Output Color Space defaults to Rec.709." Change it under `Sequence > Sequence Settings` → *Color* tab → *Color setup* menu. The same page names the default preset **"Direct 709 (SDR): This is the default, intended mainly for SDR workflows using a Rec.709 SDR working color space, outputting to Rec.709. It allows SDR media to pass through while wide-gamut camera raw and log-encoded sources are tone-mapped and gamut-compressed on input."** Other options: Direct HDR (HLG), Direct PQ (HDR), Wide Gamut (Tone Mapped / Minimal Tone Mapping / No Tone Mapping), **Disable Color Management** ("disables both the automated input to working color space conversion and the automated working to output color space conversion"). — https://helpx.adobe.com/premiere-pro/using/configure-sequence-color-management.html (Jan 7 2026). (Adobe's page uses both "Broadcast 709 (SDR)" and "Direct 709 (SDR)" for the default; the Viewer Gamma page below calls it "Direct Rec. 709 (SDR)".)
- *Auto Tone Map Media* is a sequence setting listed on the Settings tab (Sequence settings reference, above). It only acts on media of higher dynamic range than the working space; for SDR PNGs and SDR footage in a Direct 709 sequence it does nothing, so leave the default or untick it, but **never choose a Wide Gamut preset for projector files**: "output tone mapping, as configured in the Wide Gamut (Tone Mapped) preset, can have the effect of slightly darkening SDR media" (same page).
- *Export Color Space* "Defaults to Rec. 709 for most presets." — export settings reference (Aug 18 2026), https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/overview-of-export-settings.html
- *Viewer Gamma* (`Lumetri Color > Settings > Project`): 2.4 (Broadcast), 2.2 (Web), 1.96 (QuickTime). "Changing Viewer Gamma does not change how your video is exported." It "requires Lumetri Color > Settings > Sequence > Color Setup is set to Direct Rec. 709 (SDR) or Disable Color Management" (v25.2 and earlier note). — https://helpx.adobe.com/premiere-pro/using/why-do-my-premiere-pro-exports-look-washed-out.html (Apr 1 2025). For projector work set **2.2** so the Program Monitor on a Windows desktop roughly matches what the projector's player will show **[derived]**.
- Stills: "prepare images in a video-friendly color space, such as sRGB" — https://helpx.adobe.com/premiere/desktop/organize-media/import-files/import-still-images.html (Apr 1 2026). The mapper's PNGs are untagged sRGB-ish 8-bit; nothing to convert.

## 4. Importing the exports

**PNG mattes** — PNG is a supported still format (supported-file-formats page, Sep 30 2026). "An imported still image uses the duration specified in the Still Image preferences. You can change the duration of a still image in a sequence." (import-still-images, Apr 1 2026). Because the mapper writes alpha = 255 everywhere, use the matte **by luminance** (Track Matte Key → *Composite Using: Matte Luma*; §5). To stop Premiere scaling a 1280×768 PNG in a 1280×768 sequence, leave Motion at Scale 100 and do **not** use *Set To Frame Size* unless sizes differ ("When you use the Set To Frame Size command, the image's native pixel resolution is preserved" — https://helpx.adobe.com/premiere/desktop/organize-media/import-files/resize-imported-images.html, Oct 2026 snapshot). If a PNG matches the sequence exactly, it lands pixel-for-pixel at Scale 100 / Position centre **[derived from square-pixel, same-size geometry]**.

**SVG** — **Premiere Pro does not import SVG.** The supported still-image table (Sep 30 2026) lists AI/EPS, BMP/DIB/RLE, DPX, EPS, GIF, ICO, JPEG, PNG, PSD, PTL/PRTL, TGA, TIFF — no SVG (https://helpx.adobe.com/premiere/desktop/organize-media/import-files/supported-file-formats.html). The 26.5 release notes mention no SVG import either (https://helpx.adobe.com/premiere/desktop/whats-new/release-notes.html, Oct 2026 snapshot). Third-party summaries agree (blinkl.io, July 2026; Adobe Community threads 2021–2023). Routes:
1. **Rasterise the guide to PNG at exactly W×H** and import that. The SVG's `width`/`height`/`viewBox` already equal the projector pixels, so any renderer at 100 % gives a 1:1 raster: e.g. ImageMagick `magick guide.svg guide.png`, Inkscape `inkscape guide.svg --export-type=png --export-filename=guide.png`, or a browser screenshot of the SVG at 100 % zoom **[unverified: exact CLI flags not re-checked this pass]**. Photoshop opens SVG via `File > Open` with a *Rasterize SVG Format* dialog (width/height/resolution) **[unverified: third-party description, bwillcreative.com]**. Keep the background transparent so it overlays.
2. **Illustrator → .ai**: open the SVG in Illustrator, set the artboard to W×H px, save `.ai`, import. "Premiere converts path-based Illustrator art into the pixel-based image format used by Premiere, a process known as rasterization. Premiere automatically anti-aliases… converts all empty areas into an alpha channel… If you want to define the dimensions of the Illustrator art when it's rasterized, use Illustrator to set crop marks in the Illustrator file." Layers are merged; `Edit > Edit Original` reopens the file. — https://helpx.adobe.com/premiere/desktop/organize-media/import-files/import-photoshop-and-illustrator-files.html (Jan 7 2026).
3. Paid converters (e.g. aescripts "SVG2Premiere", which "automatically convert[s] them to high-quality PNG files") exist but add nothing over route 1 **[unverified]**.

**Guide layer in Premiere** — there is no guide-layer concept (that is an After Effects feature, `after-effects.md`). The working pattern **[derived]**: put the rasterised guide on the **top video track**, Opacity ~50 %, Blend Mode *Screen* so lines add light and never darken content, and before export either hide the whole track with the track's **Eye icon** ("Select the Eye icon for video… at the left edge of the track. It excludes all tracks of the same type" when Shift-clicked — https://helpx.adobe.com/ie/premiere/desktop/edit-projects/change-clip-sequence/edit-track-appearance.html, search snippet **[unverified wording]**) or delete the clip. Name the track `GUIDE – DO NOT EXPORT`. Per-clip *Enable/Disable* exists in the clip context menu **[unverified this pass]**. Always confirm on the exported file (checklist).

## 5. Track mattes in current Premiere Pro

**State of the art (verified Jan 2026 reference page):** the *Track Matte Key* effect is still the documented, current tool; the Keying effects reference (Jan 7 2026) lists Alpha Adjust, Color Key, Luma Key, **Track Matte Key** and Ultra Key. "The Track Matte Key reveals one clip (background clip) through another (superimposed clip), using a third file as a matte that creates transparent areas in the superimposed clip. This effect requires two clips and a matte, each placed on its own track. **White areas in the matte are opaque in the superimposed clip… Black areas in the matte are transparent, and gray areas are partially transparent.**" "You can animate a still by applying the Motion effect to the matte. If you animate a still image, consider making the matte frame size larger than the sequence frame size so that the edges of the matte don't come into view." — https://helpx.adobe.com/premiere/desktop/add-video-effects/effects-and-transitions-library/keying-effects.html

The 2025 "new masking tools" (Object Mask Tool with Ellipse / Rectangle / Pen Mask Tool, HSL/Luminance masks, *Unassigned Masks* dragged onto an effect) are **masks on effects**, not a replacement for track mattes; mask properties are *Feather*, *Expansion*, *Opacity*, *Invert*. — https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-masks/create-masks-using-shapes.html and https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-masks/adjust-mask-properties.html (Mar 9 2026). A beta announcement (Aug 31 2025) says the new masking workflows "are only functional in beta projects that support an upcoming major release"; users there still reported needing "a black & white mask and track matte key" for some shots (community.adobe.com, search snippet) **[unverified]**. No 25.x/26.x release note found that changes Track Matte Key.

**Procedure** (Adobe Learn "Add track matte key", https://www.adobe.com/learn/premiere-pro/web/add-track-matte-key, snapshot Nov 2024; wording from search snippets of the same page):
1. Background (or nothing) on V1, the **content** on V2, the **matte PNG** on V3 for the same duration.
2. Drag `Video Effects > Keying > Track Matte Key` onto the clip on **V2**.
3. In Effect Controls: *Matte* → "Video 3" ("This sets the clip on V3 to act as the matte"); *Composite Using* → **Matte Luma** ("If the clip acting as the matte is an opaque black-and-white graphic, choose Composite Using: Matte Luma"; Matte Alpha is for "a title or a graphic that contains an Alpha channel"). The mapper's PNGs are opaque, so **Matte Luma**.
4. *Reverse* checkbox inverts the matte (tutorials and community answers, e.g. tutsplus "Luma matte transitions"; option name **[unverified on helpx]**).

**Rules that matter for mapping** (mix of documented behaviour and community-reported behaviour):
- Keep the matte clip at Scale 100, Position centred, no Motion keyframes: Adobe documents that Motion on the matte moves the matte (keying page). Community experts additionally report that scaling the *content* clip that carries Track Matte Key also affects the matte, and advise nesting first **[unverified, community.adobe.com]**. The robust pattern: **nest the content first** (animate inside the nest), then apply Track Matte Key to the nest.
- One matte per surface: use the per-surface PNGs from the zip; each surface = own nested sequence on its own track pair (content track + matte track above it). Surfaces that need the same treatment can share the Shape PNG.
- Feathering: the PNG is hard-edged. Soften by nesting the matte and adding `Video Effects > Blur & Sharpen > Gaussian Blur` on the matte **[effect path unverified this pass; effect exists]** — a 10–30 px blur on the matte feathers the edge without touching the content **[derived]**. Alternatively, draw a mask on the Opacity effect of the content and use its *Feather* (Mar 9 2026 mask pages).
- Adjustment layers apply "to all layers below it in your sequence" (Adobe Learn, https://www.adobe.com/learn/premiere-pro/web/adjust-apply-color-effects-clips); create one from the Project panel's *New Item* button or `File > New > Adjustment Layer` (menu path from helpx locale copy via search snippet **[unverified]**). Put a global Lumetri (saturation, contrast) on an adjustment layer at the top of each projector sequence, **below** the guide track.
- Nested sequences: "A nested sequence is a sequence placed within another sequence… Any change you make to the source sequence automatically updates in all its nested instances." Nest by dragging a sequence from the Project panel into the timeline, or select clips and use Nest (Premiere "cuts the selected clips from the sequence, sends the selected clips to a new sequence, and nests the new sequence in the original sequence"). — https://helpx.adobe.com/premiere/desktop/edit-projects/edit-nested-sequences/about-nested-sequences.html and …/nest-a-sequence-in-another-sequence.html (Oct 2026 snapshots).

## 6. Placing and warping footage

- **Motion** (fixed effect): Position / Scale / Rotation / Anchor Point, keyframeable in Effect Controls. Vector graphics made in Premiere use **Vector Motion** instead, which "allows you to edit and transform vector graphics without rasterizing them" — https://helpx.adobe.com/premiere/desktop/add-video-effects/commonly-used-effects/edit-vector-graphics-using-vector-motion-effect.html (Oct 2026).
- **Corner Pin** (`Video Effects > Distort > Corner Pin`): "distorts an image by shifting its four corners. Use it to stretch, shrink, skew, twist, or mimic perspective and hinged motion like a door opening." Same category: *Offset* ("pans the image within a clip. Visual information pushed off one side of the image appears on the opposite side" — ideal for seamless scrolling textures), *Spherize*, *Turbulent Displace* ("uses fractal noise to create turbulent distortions… flowing water, funhouse mirrors, and waving flags"), *Magnify*, *Mirror*, *Lens Distortion*. — https://helpx.adobe.com/premiere/desktop/add-video-effects/effects-and-transitions-library/distort-effects.html (Jan 7 2026).
- **Pre-warp or let the mapper warp?** [derived] If the show is played from the mapper live, keep content *flat* (a plain rectangle per surface) and let the surface's corner pin / warp grid do the geometry. If the show is played from a USB stick (Full frame, 1:1), the content *must already be in projector space*: either build it against the Shape PNG / guide (Corner Pin a rectangular texture onto the four control points you read off the guide SVG's `row,col` labels), or render flat content and run it through `tools/bake.js`, which applies the mapper's warp for you. Never do both.
- **Text**: since 25.0 "the Essential Graphics panel is no longer included. You can now edit titles, captions… using the new Properties panel" — https://helpx.adobe.com/premiere-pro/using/about-properties-panel.html (Oct 14 2024). Use the Type tool, then the Properties panel for font/size/fill.
- **Keying for cutouts**: *Ultra Key* ("remove a green or blue screen"), *Color Key* ("key out all image pixels like a specified key color… adjusts only the alpha channel"), *Luma Key* ("remove all areas of a layer based on specific luminance or brightness levels… works best when the object… has a significantly different luminance than its background"). — keying-effects page (Jan 7 2026). For stock fire/smoke/particles on black, **Luma Key is usually unnecessary on a projector: black already projects as nothing**; use blend mode *Screen* or *Linear Dodge (Add)* instead and keep the black [derived].
- **Lumetri**: Basic Correction *Saturation* ("fine-tunes the intensity of the color"), Creative *Vibrance* ("Adjusts the saturation so that clipping is minimized as colors approach full saturation… changes the saturation of all lower-saturated colors with less effect on the higher-saturated colors") and *Saturation* ("0 (monochrome) to 200 (double the saturation)"). — https://helpx.adobe.com/premiere/desktop/correct-color/color-correction-fundamentals/basic-color-correction-options.html and https://helpx.adobe.com/premiere/desktop/correct-color/add-color-effects/apply-lumetri-looks.html (2026). Check with `Window > Lumetri Scopes` → Waveform (Luma, "IRE values between –20 to 120"), 8-bit scale option — https://helpx.adobe.com/premiere-pro/using/lumetri-scopes.html (May 24 2023).
- **Blend modes** (`Effect Controls > Opacity > Blend Mode`): *Screen* "Multiplies the complements… The result color is never darker than either input color. Using the Screen mode is similar to projecting multiple photographic slides simultaneously onto a single screen." *Linear Dodge (Add)* "the sum of the corresponding color channel values… never darker than either input color." *Multiply* "The result color is never brighter than the original. If either input color is black, the result color is black." — https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-composites/blend-mode-options.html (Mar 9 2026). On a projector, light only adds, so Screen/Add are the physically honest modes; Multiply/Darken can only remove light [derived].

## 7. Loops in Premiere

- Documented loop trick (tutvid, Nathaniel Dodson, Nov 2017 / updated Mar 2023, https://tutvid.com/premiere-pro/create-perfect-video-loop-premiere-pro/): "Split your clip in two… Swap the position of both clips… Overlap the clips by that same three seconds… Add a Cross Dissolve Transition and stretch [it] out to the three seconds (or even a little more)… Add the Loop button to the icon toolbar… Toggle Loop on and play through." MotionArray's guide describes the same cut-at-the-middle / overlap / Cross Dissolve method (https://blog.motionarray.com/learn/premiere-pro/make-a-video-loop-using-premiere-pro/, search snippet). An Adobe Community answer confirms a transition cannot be applied from a clip's out point to its in point directly, which is why the swap exists **[unverified]**.
- Design-side alternative [derived]: author elements so frame N equals frame 0 — whole cycles of every oscillation over the loop length (period = loop length ÷ integer), seamless noise via After Effects *Fractal Noise > Cycle Evolution* (`after-effects.md`), textures scrolled with *Offset* by exactly one tile per loop.
- Verify the seam by duplicating the finished sequence twice back-to-back in a check sequence and scrubbing the join at 1 fps, or export and use the player (`export-and-playback.md`).

## 8. Dynamic Link (Premiere ↔ After Effects)

- "Before creating Dynamic Link, ensure you're using the same Premiere Pro and After Effects versions. Dynamic Link won't work if there is a mismatch in major version numbers." — https://helpx.adobe.com/premiere-pro/using/dynamic-link.html (Jun 29 2023).
- `File > Adobe Dynamic Link > New After Effects Composition`: "After Effects then creates a project and composition with the dimensions, pixel aspect ratio, frame rate, and audio sample rate of the originating project… The new composition name is based on the Premiere project name, followed by Linked Comp [x]." Default duration 30 s; change it in `Composition > Composition Settings > Basic > Duration`. — https://helpx.adobe.com/after-effects/desktop/work-with-other-applications/work-with-dynamic-link/dynamic-link-effects.html (Mar 27 2026).
- Right-click selected clips → **Replace With After Effects Composition**: "The new composition inherits the sequence settings from Premiere" (same pages; also https://helpx.adobe.com/in/premiere/desktop/use-premiere-with-other-apps/working-with-other-adobe-applications/replace-clips-with-a-dynamically-linked-after-effects-composition.html, Apr 22 2026).
- `File > Adobe Dynamic Link > Import After Effects Composition` for existing comps.
- Performance: linked comps render in AE on demand; use `Clip > Render and Replace` to bake a heavy comp (dynamic-link page).
- Colour: "Premiere and After Effects interoperability works with every media format (except some still formats like PNG, TIFF, EXR, and JPEG, in which cases you might not see color consistency to the exact same level)… If you have After Effects open with a project having different color settings compared to Premiere sequence… If the two don't match, you'll receive a warning." — https://helpx.adobe.com/premiere/desktop/correct-color/set-up-color-management/premiere-after-effects-color-management-compatibility.html (Mar 5 2026). For a Direct 709 sequence set the AE project to a Rec.709 working space (`after-effects.md` §1).
